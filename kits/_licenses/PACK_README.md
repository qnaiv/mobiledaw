# Genre Drum Kits Pack

ジャンル別ドラムキット6種、合計104音。全て 44.1kHz / 16-bit WAV。
曲・デモは同梱していません（キットのみ）。

| フォルダ | 音数 | 中身と出典 |
|---|---|---|
| future_bass | 30 | TR-808実機録音(CC0)＋自作合成。タイトなキック/スネア、808一式、可愛いパーカッション |
| acoustic_live | 24 | 生音系。CC0実録（Karoryfer Big Rusty Drums / VCSL / 808実機）。クローズマイク、ベロシティ最大 |
| lofi_boombap | 11 | 生音系をローファイ加工（サンプルレート落とし＋ローパス＋軽い歪みでダスト感）＋808サブ |
| house | 13 | 自作合成のハウス/テクノ用キック・スネア・クラップ・シェイカー（make_pro_drums.py）＋808のハット/クラップ/シンバル/パーカッション |
| trap | 15 | 808一式（キック/スネア/ハット/クラップ等）＋音程付き808ベース5音（F1/G1/A1/C2/D2） |
| chiptune | 11 | 一番最初のチープな合成キット。8bit系・ゲーム音楽向け |
